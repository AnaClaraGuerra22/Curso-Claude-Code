O que é o Kimi?

  • Kimi é a família de LLMs da Moonshot AI.
  • API OpenAI-compatible: usamos a biblioteca openai.
  • Destaque para contexto longo, ideal para documentos grandes.
Pense no Kimi como um "cérebro externo" que você consulta via HTTP.

Principais modelos

kimi-latest

Aponta automaticamente para o modelo mais recente. Ótimo para testes e prototipação.

kimi-k2-0711-preview

Versão preview avançada, com forte raciocínio e janela de contexto muito grande.

kimi-k2.5

Modelo de produção balanceado: qualidade, velocidade e custo.

Por que usar a API?

⚡ Escala

Automatize milhares de chamadas sem intervenção manual.

🧩 Integração

Embuta IA em apps, chatbots, pipelines e agents.

🛠️ Controle

Temperature, formato JSON, ferramentas e streaming.

💰 Custo

Pague por tokens e escolha o modelo certo para cada tarefa.

Setup inicial

1. Instale as dependências:

# Terminal
pip install openai python-dotenv

2. Crie o arquivo .env:

KIMI_API_KEY=sua_chave_aqui

3. Configure o cliente:

from openai import OpenAI
import os

client = OpenAI(
    api_key=os.getenv("KIMI_API_KEY"),
    base_url="https://api.moonshot.cn/v1"
)

MODEL = "kimi-latest"

Primeira chamada à API

Envie uma lista de mensagens e receba a resposta:

response = client.chat.completions.create(
    model=MODEL,
    messages=[
        {"role": "system",
         "content": "Você é um tutor de Python."},
        {"role": "user",
         "content": "O que são closures?"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
temperature: 0.0 = determinístico, 1.0 = criativo.

Respostas em streaming

O texto vai aparecendo aos poucos, ideal para chatbots:

stream = client.chat.completions.create(
    model=MODEL,
    messages=[{"role": "user",
               "content": "Conte uma história."}],
    stream=True
)

for chunk in stream:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)

Cada chunk traz um pedacinho do texto.

Function Calling

O modelo decide chamar funções externas para obter dados em tempo real:

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Obtém a previsão do tempo.",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string"}
            },
            "required": ["city"]
        }
    }
}]

JSON Mode

Force o modelo a responder em JSON válido para integração com código:

response = client.chat.completions.create(
    model=MODEL,
    messages=[
        {"role": "system",
         "content": "Responda sempre em JSON."},
        {"role": "user",
         "content": "Extraia produto e nota."}
    ],
    response_format={"type": "json_object"}
)

data = json.loads(response.choices[0].message.content)

Combine com pydantic para validar schemas.

Vision: análise de imagens

O Kimi aceita imagens em base64 e descreve ou extrai informações:

import base64

with open("imagem.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode()

messages = [{
    "role": "user",
    "content": [
        {"type": "text",
         "text": "Descreva esta imagem."},
        {"type": "image_url",
         "image_url": {"url": f"data:image/png;base64,{b64}"}}
    ]
}]

Boas práticas

🔑 Segurança

Use variáveis de ambiente. Nunca deixe a chave no código.

🌡️ Temperatura

Baixa para dados, alta para criatividade.

📏 Contexto

Mantenha apenas mensagens relevantes para economizar tokens.

🧪 Testes

Valide JSON e trate erros da API com try/except.

Desafios práticos

💬 Chatbot

Crie um assistente de suporte técnico com system prompt e histórico de conversa.

🔧 Ferramenta de busca

Use function calling para consultar documentos ou uma base de conhecimento.

📊 OCR inteligente

Extraia dados de notas fiscais em imagens com Vision + JSON mode.

📄 Resumo de PDFs

Aproveite o contexto longo do Kimi para resumir documentos extensos.

🚀 Esses exercícios mostram na prática o poder dos modelos via API.
